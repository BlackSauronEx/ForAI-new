### Добавлено
- Автосоздание страницы сравнения (`compare` / `compare-products`) с shortcode `[rvn-compare-table]`, меткой в списке страниц, `noindex` и опциональной авто-вставкой таблицы в `the_content`.
- Админ-действия страницы: создать / выбрать / сбросить (с backup) / восстановить.
- Shortcode `[rvn-compare-table class="" products=""]`: живая таблица по списку посетителя или статическая по ID.
- REST `GET /rvn-compare/v1/table` — tabs/columns/rows без персональных данных в HTML страницы.
- Поля таблицы: price, sku, availability, rating, brand (если есть), weight, dimensions, short_description, description; все глобальные атрибуты WC; явные meta-поля.
- Группы полей `basic` / `size` / `specifications`, настройка порядка и включения.
- «Только различия», подсветка различий, скрытие пустых строк, tooltips значений, smart-normalize.
- `table.js` + `table.css`: вкладки, стрелки горизонтального скролла, sticky-колонка, empty state, clear tab/all.
- Настройки колонок 5/3/2 и breakpoints 1024/768; admin-вкладки Page + Table.

## 0.3.1 — 24.09.2026 — исправления по отчёту пользователя

### Исправлено
- Кнопка сравнения не появлялась на странице товара в классических шаблонах (Storefront, Astra и другие): авто-вставка была реализована только для блочных шаблонов. Добавлены штатные хуки WooCommerce для всех позиций, включая позиции поверх изображения.
- Кнопка «Сравнить» показывала две иконки одновременно: правило, скрывающее иконку «Уже в сравнении», проигрывало правилу её отображения по приоритету CSS.
- В режиме «только значок» активная кнопка получала лишний текст «Уже в сравнении» — правила режима проигрывали правилам состояния.
- «Отменить» в уведомлении о добавлении товара не работала: она всегда вызывала добавление. Теперь направление действия задаётся явно.
- Позиции поверх изображения ставились относительно колонки товара; теперь слот переносится в контейнер изображения — все четыре угла точны.

### Улучшено
- Отсчёт в уведомлении останавливается при наведении курсора и продолжается после ухода.
- При активации плагина сбрасывается кэш страниц (WP Super Cache, W3 Total Cache, WP Rocket, LiteSpeed): страницы, закэшированные до активации, больше не отдаются без кнопок.

## 0.3.0 — 24.09.2026 — итерация 2, кнопки, счётчики и уведомления

### Добавлено
- Кнопка сравнения на карточках товаров и на странице товара: 9 позиций из спецификации, классические хуки WooCommerce и блочные шаблоны (`render_block`), соблюдение исключений; позиции «на изображении» аккуратно выносятся поверх картинки, при отсутствии контейнера кнопка остаётся «после Купить».
- Два состояния кнопки — «Сравнить» и «Уже в сравнении»; повторное нажатие убирает товар; состояние восстанавливается после перезагрузки.
- Кнопка-счётчик, простой счётчик с подписью, «Очистить всё» и прогресс лимита категории — всё обновляется без перезагрузки страницы.
- Уведомления: добавлено, удалено, очищено, лимит по категории и общий лимит. Полоска обратного отсчёта, кнопка закрытия, действие «Отменить» для удаления и очистки.
- Шорткоды: `[rvn-compare-button]`, `[rvn-compare-counter]`, `[rvn-compare-counter-button]`, `[rvn-compare-clear]`, `[rvn-compare-progress]`; у всех есть аргумент `class`.
- Синхронизация вкладок: события `storage` и `BroadcastChannel`, обновление при возврате на вкладку и при восстановлении страницы из кэша браузера.
- Кэш-совместимость: список живёт в браузере и подгружается поверх готовой страницы; маршрут `GET /session` отдаёт свежий ключ защиты, если разметка была отдана из кэша.
- Настройки кнопок и уведомлений в хранилище: позиции, режимы для компьютера и телефона, тексты кнопок (пустое значение = перевод), позиция и длительность уведомлений, акцентный цвет с вычислением оттенков, отступы панелей.
- Безопасные зоны экрана: скрипт дописывает `viewport-fit=cover`, а элементы у края учитывают системную полоску и вырезы.

### Изменено
- Ассеты подключаются только на страницах, где есть элементы сравнения (магазин, категории, товар, корзина, поиск или страница с шорткодом).
- Данные скрипту передаются явным inline-скриптом вместо `wp_localize_script`.

### Исправлено
- Кнопки на карточках теперь подключают скрипт (раньше могли выводиться без обработчика).
- Порядок подключения ассетов: подключение из рендера блоков происходило раньше очереди скриптов, из-за чего терялись данные и стили.
- `add_filter` вместо `add_action` для фильтра `render_block`.

## 0.2.0 — 24.09.2026 — итерация 1, ядро сравнения

### Добавлено
- Хранилище списков: гость — список браузера (сервер его нормализует и проверяет), авторизованный — JSON `{"v":1,"ids":[…],"ts":…}` в пользовательской опции `rvn_compare_list` (отдельно для каждого сайта сети).
- Сервис сравнения: чтение, добавление, удаление, очистка, слияние при входе. Дубли и недоступные товары (черновики, приватные, вариации, удалённые) отбрасываются; при снижении лимита лишнее отсекается с конца; слияние идемпотентно.
- Лимиты 50 всего и 12 на категорию/группу с железным правилом: заполненная вкладка блокирует добавление, в ответе — понятная причина и заполненная вкладка.
- Модель категорий: только прямые категории; правило сравнения (по категориям, по верхнему уровню, без разделения); игнорируемые категории; группы категорий (категория принадлежит одной группе); группа «Прочее» с редактируемым названием.
- Исключения товаров и категорий для авто-кнопок (по контекстам «карточка» и «страница товара»), исключение побеждает.
- REST API `rvn-compare/v1`: `GET /list`, `POST /items`, `POST /items/remove`, `POST /clear`, `POST /merge`. Чтение — всем, изменения — только с ключом `wp_rest`; слияние ограничено по частоте (20/мин), адрес клиента хранится только хешем.
- Страница «Инструменты → Диагностика RVN»: окружение сайта и копируемый отчёт.
- Автотесты ядра (34 проверки) и REST-смоук (10 проверок) на стендах, команда `wp-dev/check.sh tests`.

### Исправлено по итогам проверок
- Отрицательные ID больше не превращаются в валидные (`absint(-1)` давал 1).
- Слияние не обрезает гостевой список до лимита до начала логики пропусков.
- Неявно-нулевой параметр заменён на явный `?array` — совместимо с PHP 8.4.

## 0.1.0 — 23.09.2026 — итерация 0, каркас плагина

### Добавлено
- Главный файл с заголовком каталога: WordPress 6.4+, PHP 8.1+, WooCommerce 8.2+ (протестировано до WordPress 7.1 и WooCommerce 11.1).
- Проверка PHP в главном файле без синтаксиса PHP 7.1+: при старом PHP — уведомление вместо фатальной ошибки.
- Проверка WordPress и WooCommerce с уведомлением и ссылками «Установить WooCommerce», «Активировать WooCommerce» (с nonce ядра) и «Перейти к обновлениям»; уведомление исчезает само.
- Декларации совместимости WooCommerce: HPOS, блоки корзины и оформления заказа, блочный редактор товаров.
- Общее ядро линейки RVN: меню «RVN» со значком «R» сразу после «Маркетинга», подпункты «Сравнение» и «Поддержка», защита от дублей и конфликтов при нескольких плагинах линейки (загружается самая новая копия ядра).
- Страница «Сравнение» (пока — таблица состояния системы) и ссылка «Настройки» на экране «Плагины».
- Версия данных и установка, в том числе ленивая установка на сайтах сети при сетевой активации.
- Удаление данных с учётом настройки `delete_data_on_uninstall` (по умолчанию — удалять) и мультисайта; страница сравнения не удаляется никогда.
- Русский перевод, шаблон POT, файлы MO и `.l10n.php`.
- Действие `rvn_compare_loaded` для сторонних разработчиков.

### Инструменты разработки (не входят в ZIP)
- `wp-dev/stand.sh` — стенды WordPress + WooCommerce на MariaDB, PHP 8.1–8.4.
- `wp-dev/check.sh` — все проверки одной командой; `wp-dev/build-zip.sh` — сборка ZIP; `wp-dev/i18n.sh` — переводы; `wp-dev/seed.php` — тестовый магазин; `wp-dev/e2e/` — браузерные сценарии.
