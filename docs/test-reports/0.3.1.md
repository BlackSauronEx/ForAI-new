# Отчёт о проверке сборки 0.3.1

**Дата:** 24.09.2026 · **Итерация:** 2a (исправления по отчёту пользователя) · **Итог:** все проверки пройдены.

## Исходные данные: отчёт пользователя с реального хостинга

Тема Storefront 4.6.2, WordPress 7.1.2, WooCommerce 11.1.2, PHP 8.3.33, WP Super Cache включён, проверка с Android (Chrome) и с компьютера.

| № | Замечание | Причина | Статус |
| --- | --- | --- | --- |
| 1 | В кнопке «Сравнить» две иконки; на телефоне тоже две без текста | Приоритет CSS: правило `.rvn-icon-in-list` (0,1,0) проигрывало `.rvn-compare-button .rvn-button-icon` (0,2,0) | Исправлено |
| 2 | «Уже в сравнении» — одна иконка, на телефоне появился текст | Правила режима (0,2,0) проигрывали правилам состояния (0,3,0) | Исправлено |
| 3 | «Отменить» при добавлении товара не работает | Обработчик всегда вызывал добавление, а товар уже был в списке | Исправлено: направление задаётся явно |
| 4 | Кнопки нет на странице товара (на карточках «Похожих товаров» есть) | Авто-вставка была реализована только для блочных шаблонов; Storefront — классический шаблон | Исправлено: добавлены хуки `woocommerce_single_product_summary` и `woocommerce_after/before_add_to_cart_button` |
| 5 | `[rvn-compare-progress]` показывает «0 из 12» | Ожидаемо: шорткод показывает прогресс вкладки, а вкладок на странице магазина нет; реальные значения появятся на странице сравнения | Не дефект; документировано |
| 6 | Кнопки не появились на телефоне, пока не очищен кэш | Страницы были закэшированы до активации плагина — WP Super Cache отдавал их без кнопок | Исправлено: сброс кэша страниц при активации |

Дополнительно реализовано: пауза отсчёта уведомления при наведении (просьба пользователя, без отдельной настройки — настройка появится вместе с вкладками дизайна).

### Проверки исправлений (Chromium, Storefront, 13/13)

- Обычное состояние кнопки: видна ровно одна иконка; текст «Сравнить» виден.
- Активное состояние: одна иконка (галочка), текст «Уже в сравнении» виден, иконки «Сравнить» нет.
- «Отменить» в уведомлении о добавлении удаляет товар; кнопка возвращается в состояние «Сравнить».
- Телефон (390 px, сенсорный): режим «только значок» — текст скрыт в обоих состояниях, иконка одна.
- Наведение на уведомление ставит отсчёт на паузу, уход курсора возобновляет.
- Страница товара: кнопка сравнения присутствует.

## Не проверено

- Позиции поверх изображения на Storefront визуально (сценарий проверил факт наличия кнопки; точность углов оценивается по скриншотам пользователя в следующей итерации).
- Мультисайт, HPOS выключен, реальные устройства, платные темы и конструкторы.
