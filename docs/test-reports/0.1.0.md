## Найдено и исправлено в ходе итерации

1. **Plugin Check, 8 предупреждений о префиксах.** Сканер Plugin Check вывел префикс плагина из корня пространства имён `Revolen` и счёл хуки `rvn_compare_*`, `rvn_core_*` и глобальные переменные `uninstall.php` неправильно названными. Исправлено по существу: пространства имён → `RVN_Compare` и `RVN_Core` (совпадают с префиксом `rvn_compare`); фильтры ядра заменены методом `Core::add_product()`; код `uninstall.php` перенесён в функцию, глобальных переменных нет. Варианты предварительно проверены на самом сканере.
2. **Plugin Check, 1 предупреждение о `load_plugin_textdomain()`.** Встроенный перевод ru_RU — требование ТЗ; языковые пакеты WordPress.org всё равно имеют приоритет. Оставлено с обоснованием в комментарии `phpcs:ignore`.
3. **PHPCS:** строковый идентификатор `'wordpress'` (правило написания WordPress) → `'wp_version'`; `count()` в условии цикла → переменная; выравнивание докблока.
4. **PHPStan:** проверки типов данных от хуков считались лишними → `treatPhpDocTypesAsCertain: false`; защитные проверки оставлены — данные хуков приходят от стороннего кода.

## Не проверено в этой итерации

- Мультисайт: удаление по всей сети и ленивая установка при сетевой активации — в полной матрице.
- Режим хранения заказов в записях WordPress (HPOS выключен) — в полной матрице; плагин заказы не читает и не изменяет.
- Уведомление при PHP ниже 8.1 — только статически (главный файл читается на PHP 7.0+); живого старого PHP на стенде нет.
- Реальный iPhone, платные темы и конструкторы — на сайте пользователя.
