# Отчёт о проверке сборки 0.4.0

**Статус:** черновик, runtime-проверки не закрыты.  
**Этап:** итерация 3 — страница сравнения и таблица.  
**Последняя подтверждённая сборка до этой итерации:** 0.3.1.

## Что проверено в этой сессии

- В трёх местах версии совпадает `0.4.0`: заголовок плагина, `RVN_COMPARE_VERSION`, `Stable tag`.
- В дереве присутствуют `Comparison_Page`, `Table_View`, `Table_Fields`, `Table_Data`, `/table`, `table.js`, `table.css`, admin Page/Table settings.
- Проверены маршруты REST, nonce-путь через `Nonce_Recovery`, кэшируемая HTML-оболочка и отсутствие персональных ID в динамической таблице.
- Проведено статическое ревью frontend/backend 0.4.0.
- Исправлено раннее состояние роли в `compare.js`: авторизованная вкладка больше не обрабатывается как гостевая до первого ответа REST.
- Исправлено поведение отключённой группы: теперь скрываются и заголовок, и строки группы.
- Boolean meta-поля теперь отображаются как локализуемые «Yes/No», а не сырые `1/0`.
- Исправлена проверка локальных URL в `[rvn-compare-*]`: обход через `example.com.evil.test` больше не проходит проверку префиксом.
- Заголовок автоматически созданной страницы переведён через text domain.
- В toast закрытие теперь создаётся через `textContent`, без `innerHTML`.
- В `wp-dev/tests/rest-smoke.py` добавлены проверки динамического и статического `/table`.
- В `wp-dev/tests/core-logic.php` добавлены проверки построения таблицы и базового поля цены.
- Добавлен `wp-dev/e2e/table-smoke.cjs`: временная статическая страница, браузерная проверка таблицы и screenshot с последующим удалением страницы.
- Добавлен режим `bash wp-dev/check.sh table [main|min]`.

## Что пока не подтверждено

- `bash wp-dev/check.sh static` (PHP 8.1–8.4, PHPCompatibilityWP, PHPCS, PHPStan, i18n).
- `bash wp-dev/check.sh tests main` и `tests min`.
- `bash wp-dev/check.sh stand main` и `stand min`.
- `bash wp-dev/check.sh table main` и `table min`.
- `bash wp-dev/check.sh pcp`.
- `bash wp-dev/check.sh cache` с настоящим WP Super Cache.
- Ручной чек-лист из `docs/TESTING.md`.
- Финальная пересборка `.mo` / `.l10n.php` после добавления строк `Yes` / `No`.
- Пересборка ZIP после правок этой сессии и финального i18n-прогона.

В текущем инструментальном сеансе доступна сборка Vite-дашборда, но не предоставлен
исполняемый PHP/WP-CLI shell для запуска стендов. Поэтому этот файл намеренно не
называет 0.4.0 проверенной: следующий чат/сессия должен выполнить команды выше.

## Критерий закрытия

Перевести статус из `черновик` в `проверена` только после зелёных static/tests/stand/table/pcp/cache,
ручной проверки на Storefront и появления скриншотов в `public/reports/0.4.0/`.
