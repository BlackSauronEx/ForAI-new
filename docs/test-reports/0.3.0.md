## Найдено и исправлено в ходе итерации

1. **Кнопки на карточках были нерабочими.** Авто-вставка выводила разметку, но не подключала скрипт: посетитель видел кнопку без обработчика. Исправлено явным подключением ассетов там, где выводится кнопка.
2. **Данные не доходили до скрипта.** Первый вызов подключения происходил из рендера блоков — раньше, чем WordPress формирует очередь скриптов (`did_action('wp_enqueue_scripts') === 0`), поэтому `wp_localize_script`/`wp_add_inline_script` молча не срабатывали, а CSS и JS терялись. Подключение перенесено на штатный хук с флагом необходимости, данные добавляются один раз с проверкой состояния.
3. **Фатальная ошибка после правки** (обращение к удалённому методу) — поймана страницей `HTTP 500` и стеком в журнале; файл переписан целиком, проверка повторена.
4. **`add_action` вместо `add_filter`** для фильтра `render_block` — нашёл PHPStan.
5. **Короткий тернарный оператор** и **отсутствие комментариев для переводчиков** — замечания PHPCS, исправлены.
6. **Нестабильный тест REST**: выборка товаров изредка возвращала пустой список сразу после других операций. Тест сделан устойчивым (повтор выборки), ложных падений больше нет.
7. **PHPStan упирался в память песочницы** — переведён на один процесс и запас в 2 ГБ.

## Что дала проверка на реальном хостинге пользователя

Хостинг: openresty, PHP 8.3.33, память 256 МБ, тема Storefront 4.6.2, HPOS, **включённый WP Super Cache** (в HTML есть маркер `Cached page generated by WP-Super-Cache`), активны Query Monitor, Plugin Check, WP Super Cache.

- REST плагина отвечает снаружи: `GET https://…/wp-json/rvn-compare/v1/list` → `{"status":"list","user":"guest","ids":[],"count":0,…}`.
- Кэш страниц включён — значит сценарий «список подгружается поверх закэшированной страницы» проверяется в боевых условиях, а не только на стенде.

## Не проверено в этой итерации

- Работа кнопок при **включённом кэше** на моём стенде (WP Super Cache стоит у пользователя; на стенде кэша нет) — в полной матрице.
- Мультисайт, HPOS выключен, реальные устройства (у пользователя Android), платные темы и конструкторы.
