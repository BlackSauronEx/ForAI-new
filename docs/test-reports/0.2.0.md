## Найдено и исправлено в ходе итерации

1. **Мусорные ID принимались за товары.** `absint(-1)` превращал отрицательные значения в валидный ID 1, и тест «список без дублей и мусора» это поймал. Исправлено: приведение к целому с проверкой `> 0`, в хранилище и в настройках.
2. **Слияние обрезало гостевой список до лимита раньше времени.** Список из 5 позиций при лимите 4 терял пятую ещё до проверок — она не попадала ни в добавленные, ни в пропущенные. Исправлено: нормализация с верхним пределом 50, а решения о пропусках принимает логика слияния.
3. **Неявно-нулевой параметр** (`array $settings = null`) заменён на `?array $settings = null` — совместимость с PHP 8.4.
4. **Тест REST разбирал вывод WP-CLI ненадёжно** и строил URL с двумя вопросами; исправлено: параметры вторым аргументом запроса, из вывода берутся только числа.

## Не проверено в этой итерации

- Мультисайт (сетевая активация, удаление по сети) — полная матрица.
- HPOS выключен — полная матрица.
- Реальный iPhone/Safari (у пользователя только Android) — остаётся «не проверено».
- Видимый интерфейс покупателя — его ещё нет, кнопки и таблица в итерациях 2–4.
